# Todo App - Angular + Ionic

Este projeto é um aplicativo de tarefas (Todo) desenvolvido com Angular e Ionic, inspirado em um design mobile do Figma.

## Como rodar o projeto

1. Instale as dependências:
   ```sh
   npm install
   ```
2. Rode o app em modo desenvolvimento:
   ```sh
   ionic serve
   ```

## Estrutura
- Angular + Ionic
- Pronto para customização visual conforme o Figma

## Personalização
Adapte os componentes e estilos em `src/` para seguir o design do Figma.
